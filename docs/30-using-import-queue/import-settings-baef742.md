# Import Settings

Import settings control when and how transport requests are imported into a transport node in SAP Cloud Transport Management.

Use these options to automate or customize the import process beyond the default manual import behavior.

The following settings are available:

-   **[Schedule Imports](schedule-imports-110a7a4.md "To run imports of all transport requests in a transport node regularly, you can
		schedule them to run at regular intervals.")**  
To run imports of all transport requests in a transport node regularly, you can schedule them to run at regular intervals.
-   **[Enable Automatic Import](enable-automatic-import-9171d39.md "To enable immediate imports of transport requests as soon as they enter a new queue, you
		can enable the automatic import for a transport node.")**  
To enable immediate imports of transport requests as soon as they enter a new queue, you can enable the automatic import for a transport node.
-   **[Disable the Import](disable-the-import-f810a35.md "To prevent imports from happening in a specific transport node, you can disable the
		import for the transport node.")**  
To prevent imports from happening in a specific transport node, you can disable the import for the transport node.
